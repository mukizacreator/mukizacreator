## 🚀 Projects

### [DeepRWA — Your AI Guide to Rwanda](https://deeprwa.agentdomains.co)
A free, multilingual AI assistant specialised in everything about Rwanda — history, culture, tourism, geography, education, agriculture, and daily life.

- 🧠 Multi-provider AI waterfall (Groq, Gemini, Cloudflare, OpenRouter, NVIDIA, Pollinations)
- 🌍 Answers in any language — Kinyarwanda, English, French, Swahili, Arabic, Chinese, and more
- 📎 Reads images, PDFs, and text files
- 💬 Persistent chat history, message versioning, public sharing
- 🔐 Email-verified signup, optional 2FA, per-device session control
- 📱 Fully responsive — phones, tablets, foldables, touch laptops, desktops

**Live:** [deeprwa.agentdomains.co](https://deeprwa.agentdomains.co) · **Source:** [github.com/mukizacreator/deeprwa](https://github.com/mukizacreator/deeprwa)

### [OnlineFileConverter](https://github.com/mukizacreator/onlinefileconverter)
A browser-based file-conversion tool. Built with plain HTML/JavaScript for maximum portability.
